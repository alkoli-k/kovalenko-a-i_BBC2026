# kovalenko-a-i_BBC2026
В папке dz1 находится домашнее задание 1, состоящее из четырех задач (калькулятор с 4 if, калькулятор с 4 функциями, калькулятор с использованием 1 функции, калькулятор "расчет баллов егэ" с помощью классов).

В папке dz2 находится домашнее задание 2 (игра с 5 уровнями на использование различных методов).

В папке dz3 находится домашнее задание 3 лабиринт, в котором главный герой пытается сбежать от злого стоматолога.на пути ему встречаются монстры, лифт, который переносит его между комнатами, герой собирает конфеты и пытается найти ключ, чтобы выйти из лабиринта

В папке dz4 находится домашнее задание 4 (практическая работа "анализ и обработка данных с использованием Pandas и NumPy")

В папке dz5 находится домашнее задание 5 (в файле interface_tkinter.py находится интерфейс регистрации и покупки подписки на сервис с открытками сделанный через библиотеку tkinter, в файле interface_QtPy.py находится тот же интерфейс покупки подписки на сервис с открытками, сделанный через библиотеку PyQt5)
